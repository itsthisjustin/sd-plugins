# Sort EPUBs by Author

Tidy a folder of EPUBs by filing each book into a subfolder named for its
author.

This plugin has no screen on the reader itself — it runs from the device web
page in a browser.

## Use (from a browser)

1. Open the device web page, go to the **File Manager**, and browse to the
   folder with the EPUBs you want to sort.
2. Open the **Sort EPUBs by author** card and tap **Organize this folder**.
3. Each book moves into a subfolder named for its author (created if it doesn't
   exist yet). A progress line shows what's being filed.

## Notes

- Sorts the folder you're viewing, not its subfolders.
- Only EPUB files are moved; anything else is left alone.
- Books already in their author's folder stay put, and any book whose author
  can't be read is left where it is.
